# Документация по лабораторной работе №2

## Описание

Лабораторная работа №2 (в методичке — №6) посвящена численным методам решения краевых задач для обыкновенных дифференциальных уравнений (ОДУ).

Задача имеет вид:

- $y'' + p \cdot y' + q \cdot y = f(x)$, $a \le x \le b$
- Граничные условия: $\alpha_1 y(a) + \beta_1 y'(a) = \gamma_1$, $\alpha_2 y(b) + \beta_2 y'(b) = \gamma_2$

**Вариант 24:**

- $p = 3$, $q = 2$, $f(x) = -2$, то есть $y'' + 3y' + 2y = -2$
- Граничные условия: $y(0) = 0$, $y'(1) = 1$
- Отрезок: $a = 0$, $b = 1$, число разбиений $n = 20$

## Разностная схема

Используется разностная схема (6.3)–(6.4) из методички:

- $\dfrac{y_{i-1} - 2y_i + y_{i+1}}{h^2} + p \dfrac{y_{i+1} - y_i}{h} + q y_i = f_i$, $i = 1 \dots n-1$
- Граничные условия:
  - $\alpha_1 y_0 + \beta_1 \dfrac{y_1 - y_0}{h} = \gamma_1$
  - $\alpha_2 y_n + \beta_2 \dfrac{y_n - y_{n-1}}{h} = \gamma_2$

Схема приводится к виду $y_{i-1} + d_i y_i + e_i y_{i+1} = g_i$, где
$d_i = -2 - ph + qh^2$, $e_i = 1 + ph$, $g_i = h^2 f_i$,
с граничными условиями $y_0 = \chi_1 y_1 + \mu_1$, $y_n = \chi_2 y_{n-1} + \mu_2$.

## Методы решения

Все методы решают одну и ту же сеточную систему. Номера соответствуют списку методов в методичке (номера 3 в списке нет).

1. **Метод прямой (правой) прогонки** (номер 1)
   - Прямой ход: вычисление прогоночных коэффициентов $Q_i$, $P_i$ слева направо
   - Обратный ход: $y_i = Q_i y_{i+1} + P_i$

2. **Метод обратной (левой) прогонки** (номер 2)
   - Коэффициенты $\xi_i$, $\eta_i$ вычисляются справа налево
   - Решение восстанавливается слева направо: $y_{i+1} = \xi_{i+1} y_i + \eta_{i+1}$

3. **Метод встречной прогонки** (номер 4)
   - Правая прогонка идёт до узла $k = n/2$, левая — от конца до узла $k+1$
   - Значения $y_k$, $y_{k+1}$ находятся из совместной системы, затем решение достраивается в обе стороны

4. **Метод стрельбы** (номер 5)
   - Решение ищется в виде $y = C_1 U + C_2 V + W$, где $U$, $V$, $W$ удовлетворяют разностному уравнению с начальными условиями $U_0 = 0, U_1 = 1$; $V_0 = 1, V_1 = 0$; $W_0 = W_1 = 0$
   - Константы $C_1$, $C_2$ находятся из двух граничных условий (итераций нет, задача линейная)

## Точное решение

$$y(x) = C_1 e^{-x} + C_2 e^{-2x} - 1$$

Здесь $e^{-x}$, $e^{-2x}$ — решения однородного уравнения (корни характеристического уравнения $r = -1$, $r = -2$), а $-1$ — частное решение.

Коэффициенты $C_1$, $C_2$ определяются из граничных условий по формулам Крамера:

- $C_1 = \dfrac{r_1 A_{22} - A_{12} r_2}{\det}$
- $C_2 = \dfrac{A_{11} r_2 - r_1 A_{21}}{\det}$

где:

- $A_{11} = \alpha_1 y_1(a) + \beta_1 y_1'(a)$
- $A_{12} = \alpha_1 y_2(a) + \beta_1 y_2'(a)$
- $A_{21} = \alpha_2 y_1(b) + \beta_2 y_1'(b)$
- $A_{22} = \alpha_2 y_2(b) + \beta_2 y_2'(b)$
- $r_1 = \gamma_1 - (\alpha_1 y_0(a) + \beta_1 y_0'(a))$
- $r_2 = \gamma_2 - (\alpha_2 y_0(b) + \beta_2 y_0'(b))$
- $\det = A_{11} A_{22} - A_{12} A_{21}$

Для варианта 24:
$$C_1 = -\frac{e^2 + 2}{e - 2} \approx -13.0715, \qquad C_2 = \frac{e^2 + e}{e - 2} \approx 14.0715$$

Если $\det = 0$, программа выдаёт ошибку: краевая задача не имеет единственного решения.

## Параметры и настройки

- `p`, `q`: коэффициенты уравнения
- `a`, `b`, `n`: границы отрезка и количество разбиений
- `alpha1`, `beta1`, `gamma1`: граничное условие в точке a
- `alpha2`, `beta2`, `gamma2`: граничное условие в точке b
- `h = (b - a) / n`: шаг сетки
- `d[i]`, `e[i]`, `g[i]`: коэффициенты разностной схемы
- `chi1`, `mu1`, `chi2`, `mu2`: коэффициенты граничных условий в сеточной задаче

Для другого варианта нужно изменить параметры задачи и блок с функциями `y1`, `y2`, `y0` (решения однородного уравнения и частное решение) в начале `lab2.py`.

## Запуск

- `python lab2.py` — программа спросит, какой метод использовать
- `python lab2.py 1` — метод прямой прогонки
- `python lab2.py 2` — метод обратной прогонки
- `python lab2.py 4` — метод встречной прогонки
- `python lab2.py 5` — метод стрельбы
- `python lab2.py 0` — все методы сразу (сравнение)

## Вывод данных

Программа выводит в консоль:

1. Параметры задачи, точное решение и коэффициенты сеточной задачи
2. Таблицу: номер узла, $x_i$, точное решение и решение каждого выбранного метода
3. Максимальную погрешность $\max |y_i - y(x_i)|$ для каждого метода

## Графики

Графики открываются в одном окне с двумя панелями:

1. **Слева — точное и приближённое решения**
   - Чёрная линия — точное решение
   - Маркеры методов: прямая прогонка — круги (o), обратная — квадраты (s), встречная — треугольники (^), стрельба — кресты (x)

2. **Справа — погрешность $|y_i - y(x_i)|$**
   - Для каждого метода своя линия с тем же маркером

## Примечания

- Схема (6.3)–(6.4) использует односторонние разности для $y'$, поэтому имеет первый порядок аппроксимации $O(h)$: погрешность уменьшается примерно вдвое при удвоении $n$.
- Все четыре метода решают одну и ту же сеточную систему, поэтому их результаты совпадают с точностью до ошибок округления. Их общая погрешность относительно точного решения определяется самой схемой, а не методом решения.
- Программа не проверяет устойчивость прогонки. Достаточное условие $|d_i| \ge 1 + |e_i|$ при $n = 20$ выполняется лишь почти: $|d_i| = 2.145$, $1 + |e_i| = 2.15$. На практике при $n = 20$ результаты четырёх методов совпадают.
