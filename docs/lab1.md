# Документация по лабораторной работе №1

## Описание

Лабораторная работа №3 посвящена решению линейных интегральных уравнений второго рода.

Уравнение имеет следующий вид:

- Для Фредгольма: \( \varphi(t) = \lambda \int_a^b K(t,s) \varphi(s) \, ds + f(t) \)
- Для Вольтерра: \( \varphi(t) = \lambda \int_a^t K(t,s) \varphi(s) \, ds + f(t) \)

Реализованы два метода:

1. Метод последовательных приближений: \( \varphi_{n+1} = A \varphi_n \), останов по условию \( \max|\varphi_{n+1} - \varphi_n| < \varepsilon \).
2. Сведение к системе линейных алгебраических уравнений (СЛАУ): \( (I - Q) \varphi = f \), где квадратурная формула трапеций используется для построения матрицы Q.

## Запуск

Для запуска лабораторной работы используйте команды:

- `python lab1.py 5` — вариант 5 (Фредгольм), проверка сходимости методов.
- `python lab1.py 12 --n 200` — вариант 12, 200 разбиений.
- `python lab1.py 5 --save` — сохранить график в PNG-файл.

## Проверка сходимости

Проверяются два условия сжимаемости:

- Условие по \( C[a,b] \): \( |\lambda| \cdot M \cdot (b - a) < 1 \), где \( M = \max |K(t,s)| \).
- Условие по \( L^2[a,b] \): \( |\lambda| \cdot B < 1 \), где \( B = \sqrt{\int_a^b \int_a^b K(t,s)^2 \, ds \, dt} \).

Если оба условия выполняются, методы сходятся.

## Методы решения

### Метод последовательных приближений

- Начальное приближение: \( \varphi_0 = f \).
- Итерация: \( \varphi_{n+1} = Q \varphi_n + f \).
- Остановка по критерию: \( \max |\varphi_{n+1} - \varphi_n| < \varepsilon \).

### Метод сведения к СЛАУ

- Решение уравнения \( (I - Q) \varphi = f \) с помощью функции `np.linalg.solve`.
- Сравнение результатов с методом последовательных приближений.

## Графики

Графики отображаются в следующих форматах:

1. Последовательные приближения (синяя линия).
2. Решение СЛАУ (красная линия).
3. Сравнение методов (синяя линия с толщиной 3, красная пунктирная линия).

Графики могут быть сохранены в формате PNG с помощью флага `--save`.

## Примеры использования


## Параметры

- `variant`: номер варианта (1–18).
- `--n`: количество разбиений отрезка (по умолчанию 100).
- `--eps`: точность итераций (по умолчанию 1e-10).
- `--save`: сохранить график в PNG-файл.

## Примечания

- При \( \lambda = 1 \) оператор A всегда сжимающий для Вольтерра, поэтому итерации сходятся.
- Для Фредгольма необходимо проверять условия сжимаемости.
- При несходимости метода последовательных приближений выводится соответствующее сообщение.

Все результаты отображаются в консоли, а графики — в отдельных окнах или файлов PNG.
