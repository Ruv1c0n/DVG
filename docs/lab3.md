# Документация по лабораторной работе №3

## Описание

Лабораторная работа №3 (в методичке — №7) посвящена численным методам решения краевых задач для уравнения теплопроводности.

**Вариант 17:**

- Уравнение: $u_t = u_{xx} + t$, $0 \le x \le 1$
- Начальное условие: $u(x, 0) = x$
- Граничные условия: $u(0, t) = 0$, $u(1, t) = t$

Нужно найти решение при $t = t_0$ в точках $x_i = i h$, $i = 0 \dots n$:

1. Сеточным методом (разностная схема + метод прогонки)
2. Методом Фурье (ряд до третьего члена)

## Параметры и настройки

Параметры $(n, m, t_0)$ выбираются из таблицы методички (набор 1–6), значений по умолчанию нет:

- `n`: число разбиений по оси x, $h = 1/n$
- `m`: число разбиений по времени, $\tau = t_0 / m$
- `t0`: момент времени, в который ищется решение (конечное время)

| Набор | n  | m  | t0  |
|-------|----|----|-----|
| 1     | 20 | 25 | 1.0 |
| 2     | 15 | 25 | 1.0 |
| 3     | 15 | 15 | 0.5 |
| 4     | 15 | 25 | 1.5 |
| 5     | 25 | 25 | 1.5 |
| 6     | 15 | 25 | 0.5 |

## Схемы решения

Решение на каждом слое по времени находится из системы $y_{i-1} + d_i y_i + e_i y_{i+1} = g_i$ с граничными условиями (здесь они первого рода, поэтому $\chi_1 = \chi_2 = 0$).

- **1 — неявная схема** ($\sigma = 1$)
  - Безусловно устойчива, порядок аппроксимации $O(\tau + h^2)$

- **2 — схема Кранка–Николсона** ($\sigma = 1/2$)
  - Усреднение по двум слоям по времени, порядок аппроксимации $O(\tau^2 + h^2)$

- **3 — схема повышенного порядка аппроксимации**
  - $\sigma = \frac12 - \frac{h^2}{12\tau}$, правая часть берётся в момент $t_j + \tau/2$ с поправкой $\frac{h^2}{12} f_{xx}$
  - Порядок аппроксимации $O(\tau^2 + h^4)$

- **0 — все три схемы** (режим сравнения)

## Методы решения сеточной задачи

- **1 — прямая прогонка**
  - Коэффициенты $Q_i$, $P_i$ слева направо, затем обратный ход

- **2 — обратная прогонка**
  - Коэффициенты справа налево, затем ход слева направо

- **3 — встречная прогонка**
  - Правая и левая прогонки встречаются в середине отрезка, решение достраивается в обе стороны

- **4 — метод стрельбы**
  - Решение ищется в виде $y = C_1 U + C_2 V + W$
  - Константы $C_1$, $C_2$ находятся из обоих граничных условий

## Метод Фурье

**Идея:**

- Замена $u = w + v$, где $w = x t$ удовлетворяет граничным условиям ($w(0,t) = 0$, $w(1,t) = t$)
- Для $v$: $v_t = v_{xx} + (t - x)$, $v(x,0) = x$, $v(0,t) = v(1,t) = 0$

**Собственные функции и числа:** $e_k = \sin(k \pi x)$, $\lambda_k = -(k\pi)^2$

**Разложение начального условия** $x = \sum \Phi_k \sin(k\pi x)$:
$$\Phi_k = \frac{2(-1)^{k+1}}{k\pi}$$

**Разложение правой части** $t - x = \sum g_k(t) \sin(k\pi x)$:
$$g_k(t) = A_k t + B_k,\quad A_k = \frac{2(1 - (-1)^k)}{k\pi},\quad B_k = \frac{2(-1)^k}{k\pi} = -\Phi_k$$

**Решение для коэффициентов:** $v_k' = \lambda_k v_k + g_k$, $v_k(0) = \Phi_k$:
$$v_k(t) = \Phi_k e^{\lambda_k t} + A_k \frac{e^{\lambda_k t} - 1 - \lambda_k t}{\lambda_k^2} + B_k \frac{e^{\lambda_k t} - 1}{\lambda_k}$$

**Полное решение:**
$$u(x,t) = x t + \sum_{k=1}^{N} v_k(t) \sin(k\pi x)$$

В задании берётся $N = 3$. Для оценки погрешности усечения программа дополнительно считает «эталон» с $N = 200$.

## Запуск

- `python lab3.py` — программа спросит схему, метод и набор параметров
- `python lab3.py <схема> <метод> <набор>`

Где:

- `схема`: 1 — неявная, 2 — Кранка–Николсона, 3 — повышенного порядка, 0 — все
- `метод`: 1 — прямая прогонка, 2 — обратная, 3 — встречная, 4 — стрельба
- `набор`: 1..6 (таблица $n, m, t_0$ выше)

## Примеры использования

```bash
python lab3.py
python lab3.py 1 1 1
python lab3.py 2 3 4
python lab3.py 0 2 5
```

## Вывод данных

Программа выводит в консоль:

1. Таблицу по узлам:
   - номер узла, $x_i$, значение ряда Фурье (3 члена)

2. Максимальные отклонения:
   - ряд Фурье (3 члена) от эталона (200 членов)

## Графики

Графики открываются в одном окне с двумя панелями:

1. **Слева — решение при $t = t_0$**
   - Чёрная линия — эталон (200 членов ряда)
   - Красная пунктирная линия — ряд Фурье (3 члена)
   - Маркеры схем: неявная — круги (o), Кранка–Николсона — квадраты (s), повышенного порядка — треугольники (^)

2. **Справа — отклонение сеточного решения от ряда Фурье (3 члена)**
   - Для каждой схемы своя линия с тем же маркером

## Примечания

- Ряд Фурье быстро сходится: слагаемые убывают с ростом $k$, а при $t_0 \ge 0.5$ экспоненты $e^{\lambda_k t}$ быстро затухают. Остаток после трёх членов программа печатает как отклонение от эталона.
- Отклонение сеточного решения от ряда Фурье (3 члена) включает и погрешность схемы, и погрешность усечения ряда; отклонение от эталона (200 членов) показывает только погрешность схемы.
- Граничные условия в этом варианте первого рода, поэтому ставятся точно, без дополнительной погрешности аппроксимации.
- Все четыре метода решения сеточной задачи дают одинаковый результат с точностью до округления: различия между результатами определяются выбором схемы.
