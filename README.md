# Лабораторные работы — «Пакеты прикладных математических программ»

Численные методы: решение интегральных уравнений, краевых задач для ОДУ,
уравнения теплопроводности и уравнения Лапласа. Выполнено по методическим
указаниям Д. В. Глазкова (ЯрГУ им. П. Г. Демидова, 2009) — оба PDF лежат
в корне репозитория.

## Структура

Нумерация файлов — по порядку выполнения, номера работ — по методичкам.

| Файл | Работа (методичка) | Вариант | Задача |
|---|---|---|---|
| `lab1.py` | №3 «Решение линейных интегральных уравнений» | 6 | Уравнение Фредгольма/Вольтерра 2-го рода: метод последовательных приближений + сведение к СЛАУ (формула трапеций) |
| `lab2.py` | №6 «Краевые задачи для ОДУ» | 24 | y″ + 3y′ + 2y = −2, y(0)=0, y′(1)=1: прямая, обратная, встречная прогонки, метод стрельбы |
| `lab3.py` | №7 «Уравнение теплопроводности» | 17 | u_t = u_xx + t: неявная схема, схема Кранка–Николсона, схема повышенного порядка + метод Фурье (3 члена) |
| `lab4.py` | №8 «Уравнение Лапласа методом сеток» | 16 | u_xx + u_yy = 0 в трапеции |y| = 9 − x: метод Зейделя, наискорейший спуск |

## Требования

- Python 3.10+
- numpy, matplotlib
- scipy — необязательно (только для проверки решения lab4 прямым методом)

```bash
pip install numpy matplotlib scipy
```

Программы при завершении открывают окно с графиками; для запуска без GUI
установите переменную `MPLBACKEND=Agg`.

## Запуск

### Лаб. №3 — интегральные уравнения (`lab1.py`)

Номер варианта выбирает уравнение из таблицы вариантов методички
(стр. 30–31): 1–9 — Фредгольм, 10–18 — Вольтерра.

```bash
python lab1.py              # вариант 6 по умолчанию
python lab1.py 12 --n 200   # вариант 12, 200 разбиений
python lab1.py 6 --save     # сохранить график в PNG
```

Перед решением проверяются условия сжимаемости оператора по C[a,b] и L²[a,b];
для Фредгольма дополнительно вычисляется спектральный радиус сеточного
оператора.

### Лаб. №6 — краевые задачи для ОДУ (`lab2.py`)

```bash
python lab2.py       # меню выбора метода
python lab2.py 0     # все методы сразу (сравнение)
python lab2.py 5     # только метод стрельбы
```

Методы: `1` — прямая прогонка, `2` — обратная, `4` — встречная, `5` — стрельба.
Точное решение вычисляется аналитически (константы C1, C2 находятся из
граничных условий), выводится таблица значений и max-погрешность.

### Лаб. №7 — уравнение теплопроводности (`lab3.py`)

```bash
python lab3.py          # параметры спрашиваются
python lab3.py 0 4 1    # все схемы, метод стрельбы, набор 1
python lab3.py 2 1 3    # схема Кранка–Николсона, прямая прогонка, набор 3
```

- Схема: `1` — неявная, `2` — Кранка–Николсона, `3` — повышенного порядка, `0` — все.
- Метод: `1` — прямая прогонка, `2` — обратная, `3` — встречная, `4` — стрельба.
- Набор: `1..6` — таблица (n, m, t0) из методички.

Сеточное решение сравнивается с рядом Фурье (3 члена) и эталоном (200 членов).

### Лаб. №8 — уравнение Лапласа (`lab4.py`)

```bash
python lab4.py          # параметры спрашиваются (K по умолчанию 10)
python lab4.py 1 10     # метод Зейделя, K = 10 (h = 0.1, как в методичке)
python lab4.py 2 5      # наискорейший спуск, K = 5 (h = 0.2, быстрее)
```

Границы области имеют наклон ±1, поэтому проходят точно через узлы сетки —
граничные значения переносятся без погрешности. Выводятся проверка принципа
максимума, невязка разностных уравнений и отличие от прямого решения той же
системы (через scipy, если установлен).
